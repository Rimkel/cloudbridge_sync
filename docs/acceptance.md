# 测试与验收范围

本页区分自动化测试和实际账号环境验证。真实环境结果来自开发期间的一套 Ubuntu / Windows / 百度网盘部署，不代表所有账号、网络或版本的兼容性承诺。公开记录不包含个人路径和账号数据。

## 已有验证

| 范围 | 证据 |
| --- | --- |
| 配置、路径、稳定性、增量、重试、锁、冲突、并发 | pytest 单元及可控后端测试 |
| rclone 实际读写 | 本机临时 WebDAV 集成测试，无需百度账号 |
| Ubuntu 百度网盘上传回读 | 文本和 PNG 上传、回读，本地 SHA-256 一致 |
| Ubuntu → 百度网盘 → Windows | 原生 Windows 下载 PNG，跨端 SHA-256 一致 |
| 后台发现新增图片 | 两种大小 PNG 依赖自然扫描到达 Windows，SHA-256 一致 |
| 失败队列恢复 | 46 个临时失败条目恢复成功，6908 个原成功记录未重传 |
| Ubuntu 内容缓存升级 | 6961 个旧成功记录建立缓存，未重复上传；之后空闲周期不重算历史哈希 |

开发验证使用 Ubuntu Python 3.12.3 / rclone 1.75.2，Windows Python 3.13.2 / rclone 1.75.1；后期网关诊断记录 OpenList 4.2.7。最低 Python 要求 3.11 不意味着已覆盖每个版本组合。

## 一次自动传输计时

2026-10-25，上传轮间等待 30 秒、最小文件年龄 120 秒；下载轮间等待 120 秒、Windows OpenList 目录缓存 2 分钟。保留两次稳定观察，没有手动刷新或强制传输。成功时间取两端 SQLite 并校正时钟差。

| 新 PNG | 生成至上传成功 | 上传成功至 Windows 完成 | 两端 SHA-256 |
| --- | --- | --- | --- |
| 约 192 KiB | 2 分 22 秒 | 4 分 49 秒 | 一致 |
| 约 12 MiB | 3 分 5 秒，含一次自动重试 | 4 分 7 秒 | 一致 |

同次验证，Ubuntu 无变化扫描约 8 秒，不重读所有历史文件。以上是一批两个样本，不能作为平均值、最大延迟或性能承诺。

## 发布及部署前仍需检查

- 在全新 Ubuntu 和 Windows 上按 usage.md 从零安装。
- 最低 Python 版本及多个 Windows 环境的原生测试。
- 文本跨端传输、多映射、中文与空格目录的完整真实账号流程。
- 大文件中断、进程崩溃或机器重启后的恢复与最终 SHA-256。
- Windows 文件占用、同名文件冲突和解除占用后的恢复。
- 临时断网与授权过期后的恢复；故障注入限定测试服务，不改管理通道。
- systemd 用户服务、Windows 登录任务及一键入口的重复启动、停止和会话行为。
- 删除测试源文件后，不向另一端传播删除；目标缺失时正确补传。
- 同大小云端替换的限制在文档中明确，不能宣称可靠发现所有变更。

doctor 默认只读；--write-test 显式允许上传并回读唯一测试文件，云端文件保留。部署者应使用专用测试目录完成自己的验收。
